# 💰 SpendWise – Expense Tracker

**SpendWise** is a simple and user-friendly Expense Tracker Web Application designed to help users manage their daily expenses, track income, and monitor their financial activities.

The application allows users to add, edit, delete, and categorize expenses while keeping track of their total spending and remaining balance.

## 🚀 Features

- ➕ Add New Expenses
- ✏️ Edit Existing Expenses
- 🗑️ Delete Expenses
- 💰 Calculate Total Expenses
- 📊 Category-wise Expense Tracking
- 💵 Income and Balance Tracking
- 📅 Monthly Expense Reports
- 📈 Charts and Graphs for Expense Analysis
- 🔍 Search and Filter Expenses
- 💾 Local Storage for Data Management

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and responsive design
- **JavaScript** – Functionality and dynamic operations
- **Local Storage** – Storing expense data in the browser

## ⚙️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Start managing your income and expenses.

## 🎯 Project Objective

The main objective of SpendWise is to provide a simple digital solution for managing personal finances. It helps users understand their spending habits, track expenses, and maintain better financial discipline.
